# Current authoritative sources

- WCAG 2.2 Recommendation: https://www.w3.org/TR/WCAG22/
- WCAG techniques, understanding and failures: https://www.w3.org/WAI/standards-guidelines/wcag/docs/
- WAI-ARIA Authoring Practices: https://www.w3.org/WAI/ARIA/apg/
- Accessibility Conformance Testing rules: https://www.w3.org/WAI/standards-guidelines/act/rules/
- Nuxt accessibility guidance: https://nuxt.com/docs/4.x/guide/best-practices/accessibility
- Vue accessibility guidance: https://vuejs.org/guide/best-practices/accessibility.html
- Nuxt UI documentation: https://ui.nuxt.com/docs
- axe-core rules: https://dequeuniversity.com/rules/axe/

Use WCAG as the normative target. Use framework and testing-tool documentation for implementation and detection guidance. Automated rules cover only a subset of accessibility requirements.
