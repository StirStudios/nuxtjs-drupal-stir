# Theme layer

Shared Nuxt UI configuration, Drupal presentation components, media, and layout behavior. Client projects customize these through app configuration and their brand styles.

The full [theme integration guide](https://github.com/StirStudios/nuxtjs-drupal-stir/blob/dev/docs/theme-layer.md) is maintained in the repository documentation rather than bundled into every consuming application. See also the [layout presets](https://github.com/StirStudios/nuxtjs-drupal-stir/blob/dev/docs/layout-presets.md) guide.
